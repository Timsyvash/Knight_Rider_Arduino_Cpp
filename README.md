# 🏎️ Ефект «Тікаючого вогню» (Knight Rider / KITT) на Arduino

Цей проєкт реалізує класичний ефект біжучого вогню, натхненний легендарним автомобілем KITT із серіалу *«Лицар доріг» (Knight Rider)*. 

Проєкт демонструє роботу з масивами пінів, автоматичним підрахунком розміру пам'яті та правильним використанням неблокуючого коду через `millis()`.

## 🛠️ Компоненти
* Мікроконтролер **Arduino Mega 2560**
* Макетна плата (Breadboard) та дроти
* 6 світлодіодів (будь-якого кольору)
* 6 резисторів (220 Ом)

## 🔌 Схема підключення
* **Світлодіоди:**
  * Аноди (довгі ніжки) ➡️ через резистори 220 Ом до цифрових пінів `2, 3, 4, 5, 6, 7`
  * Катоди (короткі ніжки) ➡️ до спільної шини `GND` на макетній платі

## 💻 Особливості реалізації
Замість стандартного та застарілого підходу з функцією `delay()`, у цьому скетчі використано таймер `millis()`. Це дозволяє контролеру залишатися повністю вільним для виконання інших завдань в реальному часі. 

Кількість світлодіодів можна легко масштабувати: завдяки формулі `sizeof(LedPins) / sizeof(LedPins[0])` алгоритм автоматично підлаштовується під будь-який розмір масиву без ручної зміни лічильників у циклах.
